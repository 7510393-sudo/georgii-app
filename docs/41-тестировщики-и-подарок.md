# Тестировщики и подарок приложения (07.10)

Сверено с объявлениями Apple на октябрь 2026; кнопки в App Store Connect
могут называться чуть иначе.

## Как дать приложение тестировщикам — TestFlight

Сборки уже уходят в TestFlight сами (слово «собери»). Остаётся позвать людей.

**Внешние тестировщики (любые люди, до 10 000):**
1. App Store Connect → приложение → вкладка **TestFlight**.
2. Слева **External Testing** → «+» → завести группу, например «Друзья».
3. Добавить сборку в группу. Первая сборка для внешних уходит на короткую
   проверку Apple (Beta App Review) — обычно сутки или меньше; следующие
   сборки той же версии чаще проходят сразу.
4. Позвать людей: по адресам почты **или** включить **Public Link** —
   ссылку можно переслать кому угодно (в сообщении, в чате). Можно
   ограничить число мест по ссылке.
5. Тестировщик ставит приложение **TestFlight** из App Store, открывает
   ссылку или письмо — и ставит Хронотеку.

**Что важно знать:**
- Каждая сборка в TestFlight живёт **90 дней**, потом перестаёт
  открываться — нужна новая сборка.
- Записи тестировщика — в его папке, они не пропадут при обновлении или
  истечении сборки: это просто файлы.
- В TestFlight покупки бесплатные (песочница), платить тестировщикам не
  придётся.
- Отзывы: тестировщик делает снимок экрана в приложении → «Поделиться
  отзывом» — он приходит в App Store Connect → TestFlight → Feedback.
- В «Что проверять» (What to Test) у сборки стоит написать по-человечески,
  на что смотреть в этой сборке.

**Внутренние тестировщики** (до 100) — только люди из вашей команды в
App Store Connect (Users and Access). Для друзей проще внешние.

## Подарить приложение навсегда, без оплаты

Решение M14: приложение скачивается бесплатно, месяц всё целиком, дальше —
**разовая покупка внутри приложения**. Сама покупка в коде ещё не сделана.

**Как дарить при этой схеме — коды предложений (Offer Codes):**
- С 2025 года Apple разрешает коды предложений для **разовых покупок**
  (non-consumable), а не только для подписок. Код даёт покупку бесплатно —
  и она остаётся у человека **навсегда**, как купленная, с восстановлением
  на новом телефоне.
- Где: App Store Connect → приложение → In-App Purchases → ваша покупка →
  Offer Codes → новый код: бесплатно, нужное число кодов (одноразовые для
  каждого) или один общий код. У кода есть срок, до которого его нужно
  **ввести**; сама покупка после ввода — навсегда.
- Человек вводит код в App Store (аккаунт → «Погасить подарочную карту или
  код») или по ссылке погашения.
- Старые «промокоды для покупок внутри приложения» Apple отключила
  26 марта 2026 — новые создать нельзя, только коды предложений.
- Чтобы это работало, в приложении нужна сама покупка, и оно должно
  принимать погашенный код (StoreKit видит его как обычную покупку —
  отдельного кода почти не нужно).

**Если бы приложение продавалось сразу за деньги** (платное скачивание) —
тогда промокоды на само приложение: до 100 на каждую версию, код нужно
ввести за 28 дней, приложение после этого — навсегда со всеми
обновлениями. Но со схемой M14 это не нужно.

**Самый простой путь для нынешних тестировщиков:** пока идёт TestFlight,
всё бесплатно. Когда приложение выйдет в App Store с покупкой — разослать
им одноразовые коды предложений на бесплатную покупку.
