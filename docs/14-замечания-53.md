## 1. Почему пропадал текст «Как прошло?»

Причина в сборке ответов обратно в файл. Ответы привязаны к названию дела,
а при записи в файл оставлялись **только те, чьё название есть в сегодняшнем
списке дел**:

```swift
let kept = order.filter { (answers[$0] ?? "").isEmpty == false }
```

Всё остальное молча исчезало. Это случалось, если после написания ответа
название дела изменилось хоть на знак, дело удалили или оно оказалось
пустым и было убрано при уходе со дня.

Вторая причина в разборе файла: строка делилась по **последнему** двоеточию.
Ответ «сделал в 10:30» делился по двоеточию внутри времени, и название дела
превращалось в «Дело: сделал в 10». На следующей записи такого дела в списке
не было — и ответ пропадал уже совсем.

Обе исправлены 23.09: ответы без пары больше не выбрасываются, а разбор
сперва сверяется с настоящими названиями дел.
