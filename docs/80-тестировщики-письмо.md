# Тестировщикам — готовые тексты (14.11)

Три текста для TestFlight, готовые к вставке. Тон — P482: без «важно»,
«срочно», «не забудьте». Автор принял соглашение с Apple 13.11 — звать
можно. Порядок кнопок — `docs/41`, `docs/42`.

Перед вставкой поменять только `[ссылка]` и, если хочется, подпись.

## 1. Beta App Description

App Store Connect → TestFlight → Test Information → Beta App Description
(видят все тестировщики и проверка Apple; до 4000 знаков):

```
Graphomanus is a diary and a day planner on one page: a plan in the morning, "How did it go?" in the evening, a photo, a voice note or a place in between.
Your entries are plain text files in a folder you choose — iCloud Drive or On My iPhone. Updates never touch them, and they stay yours if you delete the app.
Testing is free: tap "Start the free month" on the first sheet; purchases in TestFlight cost nothing.
```

Feedback Email: `support@graphomanus.com`.

## 2. What to Test (первая сборка для внешних)

Поле у сборки, до 4000 знаков. Для первой сборки — общее, без
подробностей картотеки (она ещё меняется):

```
Thank you for trying Graphomanus.
Things worth a look, if you have a minute:
• Write a plan for tomorrow and tick a task today.
• Answer "How did it go?" under a task in the evening.
• Add a photo, a voice note or a place to a day.
• Swipe sideways to the calendar and the map, and back.
• Open the Files app and look at your Graphomanus folder — these are your entries.
Anything odd, slow or unclear: take a screenshot in the app and tap "Share Beta Feedback". A few words are plenty.
```

Для следующих сборок — две-три строки о том, что в этой сборке нового,
и та же последняя строка про отзыв.
