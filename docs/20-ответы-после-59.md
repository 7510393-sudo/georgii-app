## 1. Почему я отговаривал от карты и погоды

Честно: причин было две, и одна из них была неверной.

**Верная — порядок.** Пока приложение могло потерять запись, любая новая
функция была бы надстройкой над дырявым полом. Этот довод теперь
отпадает: этап А (сохранность) сделан.

**Неверная — будто карта и погода противоречат замыслу.** Я записал их в
«чего не делать» (P2, `17-свежий-взгляд.md`) рядом с ИИ и соцсетью. Но
главное правило у нас — «своих серверов нет, файлы ваши», а не
«ничего, кроме текста». Карта и погода этому правилу не мешают:

| Что | Как сделать, не нарушая замысла | Что уходит из телефона |
|---|---|---|
| **Геометка** | Координаты из фото или по кнопке, строкой в шапке файла (A9 уже принято) | Ничего |
| **Карта записей** | Карты Apple внутри приложения: булавки по геометкам из файлов | Только запрос кусков карты — как в любом приложении с картой |
| **Название места** | Системный перевод координат в адрес (Apple) — по желанию, выключаемо | Координаты — в Apple, не нам |
| **Погода** | Погода Apple (WeatherKit): до 500 000 запросов в месяц бесплатно с учётной записью разработчика. Записывается строкой в шапку: `погода: +12°, туман` | Координаты и время — в Apple |

Вывод: **беру свои слова назад.** Карта и погода — не «органайзер жизни», а
то, что человек из Day One или Diarium ждёт увидеть по привычке (об этом —
раздел 5). Стоит это недорого: геометка и погода — около недели, карта —
ещё неделя. Место в очереди — сразу за фото.

Чего по-прежнему не делать: ИИ-пересказ, соцсеть, шаблоны-анкеты. Это не
ожидаемый минимум, а чужая дорога.

## 2. Вложения: фото, видео, аудио, файлы, геометки

Согласен: пора. Устройство, которое не ломает главного обещания:

**Где лежат.** Каждое вложение — отдельный файл в своей папке, по годам,
с датой и временем в имени:

```
Chronotheca/
  Фотографии/2026/2026-09-24 08.15.jpg
  Аудио/2026/2026-09-24 21.40.m4a
  Видео/2026/…
  Документы/2026/2026-09-24 справка.pdf
```

**Как связаны с записью.** В тексте дня — обычная строка-ссылка, которую
понимают Obsidian, Typora и любой редактор разметки:

```
08:15 Туман над полем такой плотный…
![](../../Фотографии/2026/2026-09-24 08.15.jpg)
```

На экране приложение рисует на месте строки саму фотографию — так же, как
уже рисует отметки времени. В файле остаётся строка, не «OBJ».

**Геометка** — в шапке файла (`место: 54.3211, -2.7456`), берётся из
первой фотографии дня или по кнопке. В тексте — `geo:…` (P165).

**Порядок и сроки:**

| Шаг | Дни |
|---|---:|
| Фото: из галереи и с камеры, показ в записи, открыть во весь экран | 8–10 |
| Геометка из фото и по кнопке; погода | 4–5 |
| Голос: записать, показать дорожку, прослушать | 4–5 |
| Файлы: положить документ, открыть его | 3 |
| Видео: из галереи, миниатюра, просмотр | 3–4 |
| Карта записей | 4–5 |
| Файл, положенный в папку руками, виден в дне (P60) | 2 |

Около пяти-шести недель. Начинать — с фото.

## 3. Меню страниц и настройки — что в них должно быть

Правило отбора: в меню — действия **с тем, что на экране**; в настройках —
то, что меняют **раз и надолго**. Одно и то же место — в одном месте.

### Меню дня (три точки на «Сегодня»)

1. Режим изменений
2. Перенести дело на другой день
3. Поделиться днём — текстом или картинкой страницы
4. Печать дня / PDF
5. Показать файл дня в «Файлах»
6. Удалить день — в корзину на 30 дней

### Меню календаря

1. Вернуться к этому месяцу (году) — *сделано*
2. Показывать в клетках: дела / записи / фото
3. Поделиться месяцем, напечатать месяц

### Меню поиска

1. Где искать: везде / в дневнике / в плане — *сделано*
2. Что искать: всё / фото / видео / аудио / файлы / места
3. Очистить поиск — *сделано*

### Настройки (шестерёнка)

| Раздел | Что внутри |
|---|---|
| **Записи** | Где лежат (словами «Файлов») и сколько их — *сделано*; открыть в «Файлах» — *сделано*; сменить место; вернуться к прежнему; корзина |
| **Защита** | Face ID / код; прятать экран при переключении приложений |
| **Напоминания** | Включены; звук |
| **День** | Граница суток (по умолчанию 4:00); первый день недели; с чего открывать — План или Дневник |
| **Вид** | Размер текста; тёмная страница |
| **Дневник** | Отметки времени; «Как прошло?»; заголовок дня |
| **Вложения** | Брать геометку из фото; сжимать фото |
| **Перенос** | Взять записи из Day One / Apple Journal; выгрузить всё в PDF |
| **О приложении** | Версия; покупка и её восстановление; письмо автору |

Из длинного списка в концепции убрано: выбор облака (облаком занимается
папка), громкость напоминаний (системная), шрифты на выбор (одного
хорошего довольно в первой версии).

## 4. Папка: путь и первые шаги

Сделано в этой сборке (P190):

- **Путь словами «Файлов»**: «iCloud Drive › Chronotheca» вместо
  «/private/var/mobile/Library/Mobile Documents/…». Полный путь остался
  мелко ниже — для поиска вручную.
- **Сколько записей в папке** и сколько из них ещё в iCloud.
- **«Открыть папку в „Файлах“»** — одно касание, и человек видит свои
  файлы своими глазами.
- **Первые шаги на первом экране**, по номерам: нажмите «Выбрать место» →
  выберите «iCloud Drive» или «На iPhone» → «Открыть» → приложение
  предложит завести папку.

Дальше — полное предложение `16-папка.md` (три места вместо выбора
произвольной папки). Оно ждёт вашего «браться».

## 5. В каком виде выпускать приложение

### Довод автора

Человек, привыкший к минимуму, отсеивает предложения без этого минимума
как более слабые. Это верно, и у этого есть имя — **модель Кано**. Свойства
делятся на три рода:

- **Обязательные.** Их наличие не радует, а отсутствие убивает. Никто не
  хвалит дневник за то, что в нём можно вставить фото. Но без фото его
  удаляют в первый день.
- **Линейные.** Чем больше, тем лучше: скорость, аккуратность, объём.
- **Восхищающие.** Их не ждут, и они продают: у нас это тетрадь с поворотом
  страницы, план против факта, ваша папка.

Восхищающее не спасает, если нет обязательного: человек не доходит до
восторга, споткнувшись о пустую кнопку.

### Что сегодня обязательно для дневника на iPhone

Сверено с Day One, Diarium, Journey, Diarly, Apple Journal:

| Обязательное | У нас |
|---|---|
| Фото в записи | нет |
| Замок (Face ID) | нет |
| Напоминание написать / напоминания дел | нет |
| Поиск | есть |
| Календарь | есть |
| Записи не пропадают, есть на втором устройстве | есть (iCloud-папка) |
| Выгрузка / печать | нет |
| Тёмная тема | нет |
| Геометка и погода в записи | нет (у Day One, Diarium, Journey есть) |
| Английский язык | нет |

Шесть из десяти отсутствуют.

### Особая причина не выходить раньше: месяц пробы

Наша модель (M14) — месяц бесплатно, дальше £15. Человек решает, платить
ли, **за первые дни**. Если в эти дни он не может вставить фото, он не
заплатит, и второго шанса не будет: отзывы в App Store остаются навсегда,
а первые десять отзывов решают, ставят ли приложение дальше.

### Решение, которое я предлагаю

1. **Сейчас — открытая бета в TestFlight**, а не App Store. Apple
   пускает до 10 000 внешних участников по ссылке. Позвать 20–50 человек,
   ведущих дневник. Их замечания бесплатны, отзывов в магазине они не
   оставляют.
2. **Версия 1.0 в App Store — когда закрыт весь обязательный минимум**:
   фото, замок, напоминания, выгрузка в PDF, тёмная тема, геометка и
   погода, английский. Плюс то, что у нас уже есть и чего нет у других.
3. **Видео, карта, импорт из Day One, виджет — в 1.1–1.3**, по одному
   обновлению в три-четыре недели. Частые обновления сами по себе
   поднимают приложение в магазине.
4. **Не выпускать «урезанную, зато раньше».** Выигрыш — месяц, потеря —
   первые отзывы, а их не переписать.

Срок до 1.0 при этом — около **10–12 недель** (этап Б плюс вложения,
погода и тёмная тема). Выход — **декабрь 2026 — январь 2027**, как и
намечалось, только с более полной первой версией.
