# Формат архива — описание (13.11, первая редакция)

Что лежит в папке человека и как это читать. Документ нужен, чтобы любая
другая версия приложения (iPad, Mac, Android) и любой человек с текстовым
редактором читали и писали тот же архив. Шаг 2 из `docs/68`.

Написано по коду сборки 282 (`DayFile`, `Plan`, `Diary`, `DayEvents`,
`Vault`, `Place`). Разделы, помеченные «уточнить», прочитаны не до конца —
их надо сверить с кодом и закрыть образцами-эталонами (шаг 3).

## 1. Правила, которые важнее формата

1. **Файл принадлежит человеку.** Всё, чего программа не поняла, она
   возвращает в файл нетронутым и на прежнем месте. Файл без шапки, с чужими
   строками, написанный в другом редакторе, — открывается.
2. **Не писать поверх непрочитанного.** Файл есть, но не читается (ещё в
   облаке) — день закрыт для правки.
3. **Не затирать чужую правку.** Перед записью файл перечитывается;
   изменился — своя версия кладётся рядом (§8).
4. **Пустой день не оставляет файла.** Файл заводится, когда в дне что-то
   есть.
5. **Писать целиком**: во временный файл и переименованием, чтобы обрыв не
   оставил половину.
6. Кодировка — UTF-8, перевод строки — `\n`, файл кончается переводом строки.

## 2. Папки

```
<архив>/
  Diary/2026/2026-11-13.md        запись дня
  Planner/2026/2026-11-13.md      план дня
  Photos/2026/2026-11-13_08.15.30.heic
  Videos/2026/…                   Audio/2026/…   Documents/2026/…
  Places/Дом.md                   места своей карты, файл на место
  System/chronotheca.json         метка архива
  System/<записка>.txt            «что это за папка» — для человека
  Trash/…                         корзина (§9)
```

- Год — подпапка из четырёх цифр. День — `ГГГГ-ММ-ДД.md`.
- Вложение — `ГГГГ-ММ-ДД_ЧЧ.мм.сс.<расширение>` (день записи и время
  добавления); занято — к имени добавляется ` 2`, ` 3`…: чужое не затирается.
- Запись и план дня — два разных файла с одним именем в разных папках.

## 3. Файл дня: шапка и текст

```
---
date: 2026-11-13
title: Первый снег
place: geo:51.50735,-0.12776
weather: +3 °C, snow
edited: …
---

текст
```

- Шапка необязательна. Она между двумя строками `---`; строка шапки —
  `ключ: значение` (делится по первому двоеточию). Незнакомые ключи
  сохраняются.
- Ключи дневника: `date`, `title`, `place`, `weather`, `edited`.
  Ключи места: `name`, `place`, `icon`.
- `weather` хранится в градусах Цельсия; пересчёт — при показе.
- `edited` — время последней правки человеком. *Уточнить точный вид.*

## 4. План (`Planner/…`)

Строка — дело, если после необязательных пробелов идёт `- [ ] ` или
`- [x] ` (`X` тоже):

```
- [ ] 09:00 Позвонить в банк (remind 08:30) (every week #k3f9)
      вторая строка названия
- [x] Купить хлеб
```

По порядку в строке:

| Часть | Вид | Обязательна |
|---|---|---|
| отметка | `- [ ] ` не сделано, `- [x] ` сделано | да |
| время | `ЧЧ:ММ` и пробел, 00:00–23:59 | нет |
| название | любой текст | да |
| напоминание | ` (remind ЧЧ:ММ)` в конце | нет |
| повтор | ` (every day\|week\|month\|year #код)` самым последним; код — 4–12 строчных латинских букв и цифр, один на всю серию | нет |

- **Продолжение названия** — строки с отступом (шесть пробелов) сразу под
  делом. Строка с любым отступом после дела — его продолжение.
- **Событие Календаря iPhone**, отмеченное в плане, — такая же строка с
  хвостом ` (calendar #код)` или ` (calendar #код hidden)`; код — 4–16
  знаков. Это не дело: само событие живёт в Календаре, в файле — только
  отметка «сделано» или «скрыто».
- **Вложения под делом или событием** — следующая строка, состоящая только
  из вложений (§6).
- **Нижний ряд вложений плана** (прежний вид, уходит — `docs/68`, шаг 7):
  строки только из вложений в самом конце файла после пустой строки.
- Всё остальное (заголовки, заметки, пустые строки) — не дела; хранится как
  есть.

## 5. Дневник (`Diary/…`)

```
## How did it go?
- Позвонить в банк: дозвонился со второго раза
- Купить хлеб: взял два

08:15 Проснулся раньше будильника.
Обычный текст записи.

![](../../Photos/2026/2026-11-13_08.15.30.heic)
```

- **Ответы «Как прошло?»** — необязательный блок в самом начале текста:
  заголовок `## How did it go?`, под ним строки `- название дела: ответ`.
  Ответ привязан к **названию** дела, не к номеру. Название узнаётся по
  списку дел плана этого дня (в названии и в ответе могут быть двоеточия);
  дела с таким названием нет — строка делится по первому двоеточию. Такой
  же заголовок ниже по тексту — уже текст человека.
- **Текст** — как написан. Отметка времени `ЧЧ:ММ ` в начале абзаца — часть
  текста. *Уточнить правила расстановки.*
- **Вложения в конце записи** — строки только из вложений в конце текста
  (пустые строки между ними не в счёт).

## 6. Вложения и точки

Обычные ссылки разметки, путь — относительный от файла дня:

| Что | Вид |
|---|---|
| снимок | `![](../../Photos/2026/имя.heic)` |
| видео, голос, документ | `[подпись](../../Audio/2026/имя.m4a)` |
| точка на карте | `[Название](geo:51.50735,-0.12776)` или без названия |

- Несколько вложений в одной строке — через пробел: это ряд.
- Путь с пробелами или не-латиницей может быть в угловых скобках:
  `![](<../../Photos/2026/имя 2.heic>)`. *Уточнить, когда пишется так.*
- Координаты — `geo:широта,долгота`, пять знаков после точки.
- Расшифровка голоса — текст под ссылкой на голос. *Уточнить вид.*

## 7. Места (`Places/…`)

Файл на место: имя файла — название места (знаки `/ \ : ? * " < > |`
заменены на `-`), в шапке — `name`, `place` (`geo:…`), `icon`; под шапкой —
заметка о месте.

## 8. Вторая версия

Файл дня изменили в другом месте, пока здесь была своя правка, — своя
ложится рядом: `ГГГГ-ММ-ДД — second version ЧЧ.мм.сс.md` (в русском
приложении — `— вторая версия`). Днём такой файл не считается.
*Имя зависит от языка приложения — для других платформ это неудобно;
предложение: одно английское имя.*

## 9. Корзина (`Trash/…`)

Удалённое лежит 30 дней, потом стирается. Сейчас корзин две (вложения с
описью `index.json` и дни) — сводятся в одну (`docs/68`, шаг 3); формат
описать после этого. *Уточнить.*

## 10. Метка архива (`System/chronotheca.json`)

```json
{ "приложение": "Graphomanus", "версия формата": 1, "заведено": "2026-11-13" }
```

По ней приложение узнаёт свой архив.

**Находка.** Ключи метки — русские, хотя все остальные имена в архиве
переведены на английские (P353). Для Android и для самой идеи «версии
формата» это надо поправить до выхода: `app`, `format`, `created`; прежние
ключи читать не нужно, если автор согласен убрать старые виды архива
(P905) — метка просто перепишется.

## 11. Прежние виды (убираются до выхода, P905)

До сборки 75 имена были русскими: папки «Дневник», «Планировщик»,
«Фотографии», «Видео», «Аудио», «Документы», «Служебное», «Места»,
«Корзина»; ключи шапки «дата», «заголовок», «погода», «место», «правлено»,
«название», «значок»; заголовок ответов `## Как прошло?`; напоминание
`(напомнить ЧЧ:ММ)`. Приложение до выхода читает оба вида. Автор решил
(13.11) чтение прежнего вида убрать: пользователь пока один.
