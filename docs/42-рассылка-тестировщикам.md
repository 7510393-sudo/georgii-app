# Рассылка тестировщикам — что сделать (07.10)

Порядок важен: покупки и сведения о бета-версии нужны до того, как сборку
пустят к внешним тестировщикам.

## 1. Руками автора в App Store Connect (один раз)

1. **Business → Agreements, Tax, and Banking** — принять соглашение
   **Paid Apps**, заполнить банк и налоговые формы (для Великобритании —
   форма W-8BEN). Без активного соглашения покупки внутри приложения не
   приходят даже в TestFlight — приложение тогда работает целиком, без
   пробы и покупки (так задумано, см. P432).
2. **Приложение → Monetization → In-App Purchases → «+» → Non-Consumable**
   — две покупки, ровно с такими кодами:
   - **Reference Name:** `30-day Trial`
     **Product ID:** `com.kobiashvili.diary.trial30`
     **Price:** Free (бесплатно)
     **Display Name:** «Пробный месяц» / `30-day Trial`
     **Description:** «Месяц всего приложения бесплатно» / “A month of the whole app for free”.
   - **Reference Name:** `Chronotheca Full`
     **Product ID:** `com.kobiashvili.diary.full`
     **Price:** £14.99 (ближайшая к £15 ступень)
     **Display Name:** «Хронотека навсегда» / `Chronotheca for good`
     **Description:** «Разовая покупка, без подписки» / “One purchase, no subscription”.
   - Каждой покупке нужен снимок экрана для проверки Apple (подойдёт
     снимок листка покупки) — статус «Ready to Submit» достаточен для
     TestFlight.
3. **TestFlight → Test Information** (сведения о бета-версии): описание
   приложения, адрес почты для отзывов, ссылка на политику
   конфиденциальности (готовый текст — `docs/44`, нужны только своя почта вместо `[ваша почта]` и открытая страница; можно простую: «приложение ничего не
   собирает и не отправляет; записи лежат в вашей папке»).
4. **Виджет (по желанию):** группа приложений — см. раздел 4.

## 2. Сборка

5. Сказать «собери» — свежая сборка (сейчас 111, потом 112) уйдёт в TestFlight сама.

## 3. Позвать людей

6. **TestFlight → External Testing → «+»** — группа «Тестировщики».
7. Добавить в неё свежую сборку, заполнить «What to Test» (что проверять в
   этой сборке). Первая сборка для внешних уходит на проверку Apple — обычно
   меньше суток.
8. Включить **Public Link** и разослать ссылку. Тестировщик ставит
   приложение **TestFlight** из App Store и открывает ссылку.
9. Сказать тестировщикам:
   - покупка в TestFlight бесплатна, деньги не списываются;
   - записи — их файлы, при обновлениях ничего не пропадает;
   - отзыв — снимок экрана в приложении → «Поделиться отзывом».
10. Сборка в TestFlight живёт 90 дней — дальше нужна новая.

## 4. Виджет — что это и что нужно

Виджет «Сегодня» на экране «Домой» — отдельная маленькая программа внутри
приложения. iPhone не даёт ей читать настройки и записи приложения, пока
у них нет **общей коробки — группы приложений** (App Group). Завести её
может только владелец учётной записи разработчика:

- developer.apple.com → Certificates, Identifiers & Profiles → Identifiers
  → «+» → **App Groups** → `group.com.kobiashvili.diary`;
- там же открыть `com.kobiashvili.diary` и `com.kobiashvili.diary.widget`
  → поставить галочку **App Groups** → выбрать эту группу → Save;
- профили подписи после этого обновятся — сказать, проверю, что сборка их
  подхватила.

Без группы виджет ставится, но показывает пустой день и надписи на
английском. Рассылке это не мешает.
