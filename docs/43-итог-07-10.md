# Итог 07.10 — с чего начинать новую беседу

Беседа, в которой собирались сборки 92–98, стала слишком длинной. Здесь —
всё, что нужно, чтобы продолжить с чистого листа.

## Что сделано (сборки 92–98, решения P425–P438)

- **92–93:** записи в папке на iPhone — перенос докачивает файлы из iCloud,
  после смены папки всё перечитывается, подпапка «Chronotheca» находится
  сама; поиск — с последнего заполненного дня; подсказки-стикеры для
  знакомства (`Hints.swift`); «этот и все следующие» у повторов.
- **94:** события Календаря в календаре; выбранное место и облачко на
  карте, значки; порядок «Записей», «Пора сделать», понятная копия;
  кнопки снимка внизу, «Сохранить на устройство», обзор вложений сеткой;
  перенос из Markdown/текста (`TextImport.swift`).
- **95:** плавное сердце, значки на 5% меньше, сегодня в календаре — в
  синем кружке, превью по четыре в ширину; крестик у превью в полоске;
  покупка (`Purchase.swift`, пробный месяц + «навсегда»); под записью
  четыре пустых строки.
- **96:** шапка дня ниже и цвета листа, имя и дата между стрелками;
  настройки жёлтые, меню голубое.
- **97:** мягкая граница под шапкой, строка вложений плотнее, облачко
  «…помнишь?» у «Дневника» с отступом от края.
- **98:** строки над клавиатурой тают, когда её смахивают (скачок внизу,
  P438) — на телефоне не проверено.

## Что ждёт автора (руками, в учётной записи Apple)

Подробно — `docs/42-рассылка-тестировщикам.md`.
1. App Store Connect → Business: договор Paid Apps, банк, налоговая форма
   W-8BEN.
2. Две покупки Non-Consumable: `com.kobiashvili.diary.trial30` (бесплатно,
   «30-day Trial») и `com.kobiashvili.diary.full` (£14.99). До этого
   приложение открыто целиком.
3. TestFlight → Test Information: описание, почта, ссылка на политику
   конфиденциальности.
4. (По желанию) группа приложений `group.com.kobiashvili.diary` для
   виджета — у обоих идентификаторов.
5. External Testing → группа → сборка → Public Link → рассылка.
6. Подарок после выхода — коды предложений (`docs/41`).
