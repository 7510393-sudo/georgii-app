# Названия: полный список вариантов

Все имена, прозвучавшие в работе над проектом, с исходом разбора. Составлено 15.09.2026.
Порядок внутри разделов — по ходу обсуждения, а не по качеству.

**Требование к имени.** Одинаково читается по-русски и по-английски; несёт «флёр
образованности» — ощущение, что слово придумано образованным человеком.

**Проверка перед тем, как предлагать.** Произнести вслух по-русски; подменить первую
согласную; прочитать так, как его прочтёт англичанин.

**Проверка занятости — четыре места:** App Store, Google Play, домен, реестры марок
(UK IPO, EUIPO, USPTO), классы 9 и 42. Обязательно смотреть смежные категории.

## Рабочее название: Chronotheca (16.09.2026)

Принято **как временное**, чтобы не держать разработку. Меняется одной строкой вплоть до дня
публикации.

**Написание принципиально — только `-theca`.**

| Написание | Состояние |
|---|---|
| **Chronotheca** | Свободно. В открытом поиске — только Discord-сервер на восемь человек и художественный проект на Behance. Ни компании, ни приложения, ни репозитория |
| Chronoteca | **Занято**: chronoteca.com — торговец винтажными часами, расшифровывает имя так же («CHRONO + TECA, библиотека времени»). Плюс инстаграм-двойники |
| Chronotek | **Занято**: американская фирма, учёт рабочего времени выездных сотрудников, приложение в Google Play. Смежная категория |

## 5. Механизм упорядочивания и наукообразные

Направление появилось позже других: называть не материал, а действие — то, что приложение
делает с хаосом жизни.

| Название | Автор | Исход |
|---|---|---|
| Tessera | обсуждение | **короткий список** — кубик мозаики, у римлян также табличка-жетон. Риск: Tessera Technologies (полупроводники, ныне Xperi) |
| Ordinata | обсуждение | **короткий список** — лат. «упорядоченная», в русском живёт как ось ординат. Магазины чисты; домены и марки не проверены; «ordinata» — живое итальянское слово |
| Sextant | обсуждение | **короткий список** — прибор, определяющий, где ты находишься. Риск: имя любят консалтинговые и финансовые фирмы |
| Nomos | обсуждение | **короткий список** — греч. «распределять»; корень внутри астрономии, экономии, таксономии |
| Syntagma | обсуждение | **короткий список** — греч. «приведённое в строй». Риск: площадь Синтагма в Афинах забивает поиск |
| Ordo | обсуждение | **отклонено** — по-русски в полушаге от «орды», то есть от хаоса, которому приложение противопоставлено |
| Taxis | обсуждение | **отклонено** — по-английски читается как множественное от такси |
| Gnomon | обсуждение | **отклонено** — по-английски «g» не читается; та же беда, что у «Пергамента» |
| Loculus / Loculi | обсуждение | **отклонено** — по-русски глухо |
| Abacus | обсуждение | в резерве — доска с ячейками; вероятно занято в софте |
| Pinax | обсуждение | в резерве |
| Praxis | обсуждение | в резерве |
| Analecta | обсуждение | **отклонено** — первый слог по-русски |
| Engram | обсуждение | в резерве с оговоркой — «энграмма», след памяти; слово затаскано саентологией |

Не кандидат, но отмечено: **rastrum** — латинские грабли, гребень; отсюда растр (сетка строк)
и раструм, перо для расчерчивания нотного стана. Метафора совпадает полностью, но по-русски
слово отдаёт типографией.
