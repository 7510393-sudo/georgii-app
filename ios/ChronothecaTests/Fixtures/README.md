# Эталоны формата архива (P951)

`Archive/` — маленький архив во всех видах, какие приложение должно
прочитать: шапка и без шапки, чужие ключи, дела со временем, напоминанием,
повтором, продолжением, отметки Календаря, ответы «Как прошло?» с
двоеточиями, вложения под делом и в конце, точки, голос с расшифровкой,
путь в угловых скобках, файлы из Windows (`\r\n`), файл, который начинается
чертой, вторая версия дня, места, метка архива.

Что из них должно прочитаться — `FormatFixtureTests.swift`. Описание
формата — `docs/69-формат-архива.md`. Эталон меняется только вместе с
решением в журнале: это обещание людям, чьи записи лежат в таком виде.

Файлы не входят в приложение и в набор проверок (`project.yml`,
`excludes`): проверка читает их с диска по пути исходника.
